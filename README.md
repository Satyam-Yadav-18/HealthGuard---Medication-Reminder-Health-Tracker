# SDG Project: HealthGuard

## 1. Selected SDG and Reason for Selection
- SDG selected: **SDG 3 - Good Health and Well-being**
- This SDG focuses on ensuring healthy lives and promoting well-being for all ages.
- This issue is important because missing medication or failing to track daily health habits can worsen chronic conditions and reduce quality of life.

## 2. Problem Statement
- Problem: Many people forget medication doses and lack a simple way to track daily health routines.
- Where: This problem exists in homes, eldercare settings, and communities with limited health monitoring tools.
- Who is affected: Patients with chronic conditions, older adults, caregivers, and anyone managing regular medication.
- Why it is serious: Missing doses can cause health complications, hospital visits, and reduce treatment effectiveness.
- What could happen if not solved: Users may experience worsening symptoms, drug resistance, or unnecessary stress from unclear health routines.

## 3. Proposed Solution
HealthGuard is a web application that helps users manage medication schedules and daily wellness habits. The system stores medication details, calculates the next dose time, and allows users to log mood, sleep, and water intake.

How it works:
- Users add medications with dose, interval, and start time.
- The app calculates the next dose automatically.
- Users save daily health logs for mood, sleep, and hydration.
- The app shows active medications, next reminder time, and recent health logs.

Who will use it:
- Patients taking regular medication
- Caregivers supporting family members
- Users who want to improve daily wellness habits

## 4. Project Features
- **Medication Management**: Add medicine name, dose, interval, and start time.
- **Next Dose Reminder**: Displays the upcoming medication time and alerts the user when a dose is due.
- **Health Logging**: Record daily mood, sleep hours, and water intake.
- **Local Storage**: Saves user data in the browser so schedules and logs persist.
- **Responsive Design**: Works on desktop and smaller screens.

## 5. Technology Stack
- Frontend: HTML, CSS, JavaScript
- Storage: Browser LocalStorage
